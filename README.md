## 🌟 研習亮點與內容

本成果網站記錄了 115 年 10 月 31 日於陽明高中生活科技教室（iSTEM 自造教育及科技中心 AI T-Learn）舉辦的 **「AI繪圖-小宮燈實作」** 研習活動，將前瞻生成式 AI 技術與動手生活科技完美結合：

1. **AI 魔法工作列提示詞工程**：
   - 掌握「政策規範 + 教學目標 = 專屬內容」高效詠唱公式
   - 角色一致性與在地化風格控制（台北101、夜市地瓜球、傳統中式牌樓、水彩插畫風）
2. **文創實體商品轉化**：
   - 規範化圓形構圖尺寸，直通手壓胸章機快速量產
   - 雷射切割半透明透光片設計，適配木製小宮燈
3. **生活科技木構自造**：
   - 木質榫接結構組裝、LED 光源模組配置
   - 點亮兼具文化意象與前瞻科技的個人化發光小宮燈
4. **教學與行政提速**：
   - 會議演講逐字稿即時自動辨識與重點摘要
   - 網頁版精華手冊快速生成
